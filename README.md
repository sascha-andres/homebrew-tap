# Sascha-andres Tap

## How do I install these formulae?

`brew install sascha-andres/tap/<formula>`

Or `brew tap sascha-andres/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "sascha-andres/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
